## Задача 4

### Текст задачи

Дан набор целых чисел с четным количеством элементов. Заполнить дек D исходными числами, вывести первую половину элементов дека D в обратном порядке, а затем — вторую половину (также в обратном порядке).

### Алгоритм решения

Исходный набор чисел считывается и сохраняется во вспомогательный вектор. Дек D заполняется с помощью конструктора, принимающего диапазон итераторов (от начала до конца вектора).

Для нахождения середины дека итератор, установленный на начало, сдвигается на N/2 позиций (где N — общее количество элементов) с помощью функции `advance`. Первая половина выводится с использованием обратного итератора, инициализированного позицией середины; цикл идёт до `D.rend()`. Вторая половина выводится с использованием обратного итератора от `D.end()` до итератора середины. Таким образом, обе половины выводятся в обратном порядке относительно их исходного расположения.

Первый вызов `insert` добавляет в конец вектора V диапазон элементов от начала дека до его середины (первая половина дека в исходном порядке). Второй вызов `insert` добавляет в начало дека D сохраненную вторую половину вектора V (в обратном порядке). После преобразований содержимое обоих контейнеров выводится на экран.

### Алгоритм решения

Числа считываются в вектор. Для отбора элементов используется алгоритм `remove_copy_if`, который копирует в выходной поток (связанный с `ostream_iterator`) все элементы, для которых условие ложно. При каждом вызове лямбда проверяет, является ли текущий индекс (нумерация с нуля) чётным, и увеличивает счётчик. Чётный индекс с нуля соответствует нечётному порядковому номеру, поэтому такие числа отбрасываются, а в вывод попадают числа со 2-м, 4-м и т. д. порядковыми номерами.

Остальные элементы вектора остаются неотсортированными, что делает алгоритм эффективнее полной сортировки.

Для вывода результата используется алгоритм `copy`, который копирует первые три элемента вектора в выходной поток `ostream_iterator`.

# Задание 8

## Задача 2

### Текст задачи

Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Количество элементов дека D должно быть на 1 меньше количества элементов списка L. Например, для исходного списка ABC, DEF, KLM, XYZ полученный дек должен содержать строки AF, DM, KZ. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для дека D.

### Алгоритм решения

Алгоритм `adjacent_difference` вызывается для всего списка L, а результат записывается в дек D через итератор вставки `back_inserter`. Вместо стандартной операции вычитания алгоритму передаётся лямбда-выражение, которое для текущего (правого) и предыдущего (левого) элементов пары формирует новую строку, добавляя к первой букве левого слова последнюю букву правого.

Алгоритм `adjacent_difference` записывает первым элементом результата копию первого элемента исходного диапазона, а начиная со второго — результаты применения функционального объекта к парам соседних элементов. Поэтому после его работы первый элемент дека D, не являющийся результатом склейки, удаляется функцией-членом `erase`. В итоге дек содержит на один элемент меньше, чем список L.

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, …, VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, …, VN. Найти количество векторов VI, I = 1, …, N, в которых содержатся все элементы вектора V0 (с учетом их повторений). Использовать алгоритм includes, применяя его в цикле к двум мультимножествам (контейнерам типа multiset), одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1, …, N.

### Алгоритм решения

На основе вектора V0 создаётся мультимножество (контейнер `multiset`), которое хранит элементы в отсортированном виде с сохранением повторений.

Далее в цикле для каждого вектора Vi создаётся своё мультимножество из его элементов. Алгоритм `includes` проверяет, входит ли мультимножество V0 в мультимножество Vi. Поскольку оба контейнера отсортированы и хранят повторяющиеся значения, `includes` учитывает кратность элементов: значение, встречающееся в V0 k раз, должно встречаться в Vi не менее k раз. Если проверка проходит успешно, счётчик подходящих векторов увеличивается. После обработки всех N векторов значение счётчика выводится как результат.

# Задание 10

## Задача 4

### Текст задачи

Дан вектор V, элементами которого являются английские слова, набранные заглавными буквами. Выполнить группировку элементов вектора V, используя в качестве ключа группировки последнюю букву элемента: в одну группу должны входить все элементы вектора V, оканчивающиеся одной и той же буквой (сгруппированные элементы должны располагаться в порядке, обратном порядку их расположения в исходном векторе). Представить результат группировки в виде мультиотображения M, ключами которого являются ключи группировки, т. е. последние буквы элементов вектора V, а значениями — элементы вектора, оканчивающиеся на соответствующую букву (таким образом, отображение M должно иметь тип multimap<char, string>). Вывести полученное отображение (для каждого элемента отображения M вначале выводить ключ, а затем связанный с ним элемент вектора V; ключи могут повторяться). Для перебора элементов контейнеров использовать цикл for по элементам контейнера.

### Алгоритм решения

Создаётся пустое мультиотображение `multimap<char, string>`. Элементы вектора V перебираются в обратном порядке с помощью обратных итераторов (`rbegin`, `rend`), и каждое слово добавляется в мультиотображение в паре с ключом — своей последней буквой, полученной функцией-членом строки `back`.

Мультиотображение автоматически упорядочивает элементы по ключам, то есть слова группируются по последней букве в алфавитном порядке букв. Элементы с одинаковым ключом располагаются в порядке их добавления, а так как вектор просматривался с конца, внутри каждой группы слова оказываются в порядке, обратном исходному. После этого мультиотображение перебирается от начала до конца с помощью цикла `for`, и для каждого элемента выводятся ключ и связанное с ним слово.
